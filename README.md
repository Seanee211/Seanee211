## Featured research

### Machine learning for recurrent lumbar disc herniation

**Co-first author · Journal of Korean Neurosurgical Society · Published**

A study of recurrence after lumbar discectomy using clinical variables and MRI-derived measurements. I contributed to the machine learning pipeline, analysis, and manuscript writing.

The [public research repository](https://github.com/Seanee211/rLDH-prediction) contains feature-selection, model-comparison, and SHAP notebooks, with a guide to the historical experiments and their execution requirements. Clinical data and saved notebook outputs are excluded.

[Explore the code →](https://github.com/Seanee211/rLDH-prediction) · [Read the paper →](https://doi.org/10.3340/jkns.2025.0120)
